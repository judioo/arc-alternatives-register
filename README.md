# Arc Alternatives Register

An open register of browsers built to carry on from [Arc](https://arc.net), which stops working on 22 December 2026. It lists <!-- count -->56<!-- /count --> browsers, with the facts anyone can check: engine, platforms, licence, status, website and source code.

It records facts, not opinions. There are no scores or rankings here. Sites that compare browsers can build their own on top of it.

## Use the data

- [`browsers.csv`](browsers.csv) opens as a searchable table on GitHub, or in any spreadsheet.
- [`browsers.json`](browsers.json) is the same list for code.
- [`data/browsers/`](data/browsers) has one file per browser. That's the source, and the two files above are built from it.
- [`data/leads.json`](data/leads.json) lists browsers seen elsewhere that haven't been checked yet.

The data is in the public domain ([CC0 1.0](LICENSE-DATA.md)). Use it for anything, no credit needed, though a link back helps others find it.

## Add or correct a browser

Open a pull request that adds or edits one file in `data/browsers/`. Every value needs a public source, listed in `sources`. [CONTRIBUTING.md](CONTRIBUTING.md) explains each field. A check runs on every pull request and says what to fix.

Not sure, or no time for a pull request? [Open an issue](../../issues/new/choose) instead.

## Where it started

The first entries came from [awesome-arc-alternatives](https://github.com/igorsyrbu/awesome-arc-alternatives) (CC0). Browsers found on other lists go into `data/leads.json` until someone checks them against their own website or repository.

## Who keeps it

It's maintained by people who make [Darni](https://github.com/judioo/darni), one of the browsers listed. Darni is held to the same rules as every other entry, and anyone can correct it.
